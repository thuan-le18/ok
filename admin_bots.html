🚀 Hướng dẫn chạy bot

1. Tạo file bot_runner.js (xem code bên dưới).

2. Cài Node.js, chạy npm install node-telegram-bot-api firebase-admin.

3. Tải file firebase-service-account.json từ Firebase Console.

4. Sửa databaseURL và link miniapp trong code.

5. Chạy node bot_runner.js.

💡 Bot sẽ tự động chạy polling và xử lý /start, lưu user & log chat.
